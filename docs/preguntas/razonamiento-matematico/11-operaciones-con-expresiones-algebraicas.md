# Operaciones con expresiones algebraicas

**Prueba de Aptitud Académica — Beca BCP / ESAN** · Razonamiento Matemático
**Nivel:** examen de preselección (intermedio) · **5 preguntas** · opción múltiple (A–E), una sola respuesta correcta
**Sugerencia:** repasa los productos notables: (a + b)² = a² + 2ab + b² y (a + b)(a − b) = a² − b². Resuelve en un máximo de 10 minutos.

---

**1.** Al reducir la expresión 3x + 5x − 2x + x se obtiene:

A) 5x
B) 6x
C) 7x
D) 8x
E) 11x

**2.** Halla el valor numérico de 2a² − 3a + 1 para a = 3.

A) 5
B) 6
C) 9
D) 10
E) 28

**3.** Al simplificar (x + 3)² − (x + 2)(x − 2) se obtiene:

A) 6x + 5
B) 6x + 9
C) 6x + 13
D) 6x² + 13
E) 2x² + 6x + 5

**4.** Si x + y = 10 y xy = 21, ¿cuál es el valor de x² + y²?

A) 42
B) 58
C) 79
D) 100
E) 121

**5.** Si a + 1/a = 4, ¿cuál es el valor de a² + 1/a²?

A) 12
B) 14
C) 15
D) 16
E) 18

---

## Clave de respuestas

**1. C (7x)** — 3 + 5 − 2 + 1 = 7, entonces 7x.

**2. D (10)** — 2(3)² − 3(3) + 1 = 18 − 9 + 1 = 10.

**3. C (6x + 13)** — (x + 3)² = x² + 6x + 9 y (x + 2)(x − 2) = x² − 4. Restando: x² + 6x + 9 − x² + 4 = 6x + 13.

**4. B (58)** — (x + y)² = x² + 2xy + y² → 10² = x² + y² + 2(21) → 100 = x² + y² + 42 → x² + y² = 58.

**5. B (14)** — Elevando al cuadrado: (a + 1/a)² = a² + 2 + 1/a² → 4² = a² + 1/a² + 2 → a² + 1/a² = 14.
