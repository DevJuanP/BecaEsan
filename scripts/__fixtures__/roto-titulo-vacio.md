## Clave de respuestas

**1. B (4)** — 2 + 2 = 4.

**2. D** — 4² − 3² = 16 − 9 = 7.

**3. C (S/ 30)** — 120 ÷ 4 = 30.

**4. C (16)** — 8 × 2 = 16.

**5. C (9)** — 3 × 3 = 9.
